# PalPalPal Changelog

---

# 1.0.1 - Initial Development Build

- Paint-program layers: combined image + palette layers, image-only layers and palette layers, with blend
  modes, opacity, drag to reorder, rename, Separate / Combine, Show filters and Palette Inheritance
- Timeline with play / pause, speed, loop points, frame copy / paste / delete / clone / add blank and
  Show / Hide Layer
- Projects (`.palpal`), autosaving them atomically
- Super Swatch Switcher with Simple, Advanced and NuAge skins
- Added Mass Frame Editor (img2palette) and Img2img Palette Swap features with Palette to Palette Mappers
- Artwork Tool: a full pixel art editor with nearly 50 tools, layers, and animation controls to use
- 3D bead view with 3D height settings (heightmap, per color sliders, or drawn by hand)
- Document Settings: palette size, palettes per frame (frame tabs), 3D heights and preferences
- Reads PAL, GPL, ACT, ACO, ASE, KPL, SketchPalette, KDE colors, HEX, Paint.NET TXT, JSON and image palettes
- Transparent BG option, user-defined key (see-through) color, dark mode everywhere
- 32-bit and 64-bit builds
- This manual and changelog, inside the app
- Custom image canvas alignment
- Two Preview Modes -> Small, Big, and No Preview
	- Small -> Canvas smaller; can edit pallettes
	- Big -> Canvas larger; no editing palettes
	- No -> No canvas; specifically for editing palettes
- Three Frame Display Types
	- Single -> Single frame
	- All -> All frames; clickable!
	- Custom -> Set a custom field view in the Gear Frame Options Menu next to it
- Frame Options Menu with custom frame and export selection
- 3D Layer View
- Document Settings Menu with extended color palette, 3D, UI, and more options.
- Self-Debug Options
- Several Export Options including PNG, BMP, GIF, WEBP, PAL, KPL, HEX, ASE, and more!
- Multi-index selection
- Multi-frame import
- Palette Sorting
- Click-to-index on 2D view
- Right Click Context Menu
